⚡ HOW TO RUN
═══════════════════════════════════════════════════════════════════════════

TERMINAL 1 - Backend:
  cd backend
  python -m venv venv
  .\venv\Scripts\Activate.ps1
  pip install -r requirements.txt
  python -m uvicorn app.main:app --reload --host 0.0.0.0 --port 8000

  ✅ Backend running at http://localhost:8000

TERMINAL 2 - Frontend:
  cd superr-selector
  npm install
  npm run dev

  ✅ Frontend running at http://localhost:5173

BROWSER:
  Open: http://localhost:5173

Total time: <5 minutes

📞 TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════════════

ISSUE: Backend won't start
FIX:
  - Check Python 3.11+ installed: python --version
  - Activate venv: .\venv\Scripts\Activate.ps1
  - Install deps: pip install -r requirements.txt

ISSUE: Demo mode won't disable
FIX:
  - Verify CSV files in backend/data/
  - Check use_demo = False in config.py
  - Restart backend completely
  - Check logs for error messages

ISSUE: CORS errors in browser
FIX:
  - Ensure backend running on :8000
  - Check .env has correct URL
  - Restart frontend after .env changes

ISSUE: Slow performance
FIX:
  - Reduce dataset size
  - Use smaller date ranges in filters
  - Add caching (future enhancement)
  - Consider database instead of CSV

ISSUE: Frontend won't connect
FIX:
  - Check backend is running
  - Verify .env file exists
  - VITE_API_BASE_URL should be http://localhost:8000/api/v1
  - VITE_DEMO_MODE should be false
